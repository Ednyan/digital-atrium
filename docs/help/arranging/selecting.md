# Selecting

Select traces to move, change or delete them together. The count shows on
screen: **3 traces selected**.

## Select traces

| You want | Do this |
|---|---|
| One trace | Click it with **Select** (**1**) |
| Add a trace, or take one out | **Shift**+click it |
| A trace inside a group or a frame | **Ctrl**+click it, or click it again after the group is selected |
| Everything in an area | **Selection** (**M**) > **Area selection**, then drag a box |
| Traces of any shape of area | **Selection** (**M**) > **Lasso selection**, then draw round them |
| Every trace in this group | Right-click a trace > **Select** > **Select Group** |
| Every trace in the atrium | Right-click a trace > **Select** > **Select All** |
| Nothing | Press **Esc**, or click empty canvas |

With **Select**, clicking a trace in a group picks the whole group. Click again
to pick the trace inside.

**Direct select** always picks the trace itself, even inside a group or a frame.
**Ctrl**+click does the same once, without switching tools.

## The Selection tool

**Selection** (**M**) has two ways: **Area selection** and **Lasso selection**.
What it reaches is added to what's already selected.

It stays on until you pick another tool, or press **M** or **Esc**.

## Good to know

- A selection box picks up a frame only if the whole frame is inside it.
- Area and lasso add to the selection: press **Esc** first to start over.
- **Delete** removes everything selected. **Ctrl+Z** brings it back.
- There's no select-all key: use right-click > **Select** > **Select All**.
