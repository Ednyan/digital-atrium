# Embeds and links

An embed shows something from the web, a video, a web page or a picture, live on
the canvas. Only its link is kept, so it takes almost no space.

## Add embeds

| You want | Do this |
|---|---|
| One from a link | Press **7**, click where it goes, paste the link, then **Embed** |
| Several at once | Paste several links into the same box: it counts them (**3 links**) |
| One from what you copied | Right-click the canvas > **Paste as Embed** |
| One from a site's embed code | Paste the whole `<iframe …>` code instead of a link |
| A link dropped from the browser | Drag it onto the canvas |

To change what an embed shows, select it and edit **Embed URL or HTML** in the
Customization panel.

## Use it in place

An embed is moved and selected like any trace until you turn interaction on.

| You want | Do this |
|---|---|
| Play the video, scroll the page, click inside | Right-click it > **Enable Interaction** |
| Move it again | Right-click it > **Disable Interaction** |
| The link, to open or send | Right-click it > **Copy Embed Link** |

## Keep it as a picture (desktop)

On desktop, an embed that shows a picture can become a picture of your own, kept
in your vault and shown offline.

| You want | Do this |
|---|---|
| One embed | Right-click it > **Convert to Image** |
| Every embed in the atrium | **Menu** > **Store Embeds Locally** |

## Good to know

- Some sites refuse to be shown inside another page, so their embed stays empty. Use **Copy Embed Link** to open them in the browser.
- An embed needs the internet to show: offline, it's empty unless converted to a picture on desktop.
- Pins from Pinterest can't be converted to pictures: they're always shown as Pinterest delivers them.
- **Convert to Image** and **Store Embeds Locally** are on desktop only.
